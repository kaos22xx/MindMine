# MindMine Wallet

A desktop GUI wallet for MIND token on Arbitrum.

## Requirements

- Python 3.8+
- web3.py
- Pillow
- Ethereum account (eth-account)

## Installation

```bash
pip install web3.py Pillow eth-account
```

## Usage

```bash
python mindmine_wallet.py
```

## Features

- View MIND and ETH balance
- Transfer MIND tokens
- View mined blocks count
- Load wallet via private key
- Shows token logo

## Network

- Network: Arbitrum One
- RPC: https://arb1.arbitrum.io/rpc
- Chain ID: 42161
